# Shared skill references

`performance-checklist.md` is vendored from
[addyosmani/agent-skills](https://github.com/addyosmani/agent-skills) at
`references/performance-checklist.md`.

The `performance-optimization` skill links to
`../../references/performance-checklist.md` from its own directory. The
`skills` CLI installs only the skill folder (`.agents/skills/performance-optimization`),
so the shared reference is kept here to make those links resolve. Keep it in
sync with the upstream file when the skill is updated.
